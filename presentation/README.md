# Презентация к защите ВКР «Тропа»

Презентация для защиты выпускной квалификационной работы «Разработка веб-сервиса
построения туристических маршрутов по Тульской области для людей с ограниченными
возможностями здоровья».

- **Структура** — по шаблону «презы для диплома» (17 слайдов).
- **Дизайн** — в стиле презентации Чмелева: светло-серый фон, крупные жирные
  чёрные заголовки-гротеск, рукописный курсивный акцент-слово на каждом слайде,
  монохром с акцентом на ключевых цифрах, много воздуха, асимметричная вёрстка.

## Файлы

| Файл | Описание |
|------|----------|
| `Презентация_ВКР_Тропа.pptx` | Готовая презентация (17 слайдов). Открывается в PowerPoint, можно редактировать. |
| `Доклад_к_защите.md` | Текст доклада к защите (≈5 минут), привязанный к слайдам. |
| `Вопросы_и_ответы.md` | Подготовка к вопросам комиссии: уточняющие и вероятные вопросы с ответами по всем разделам ВКР. |
| `Сценарий_видео_контрольный_пример.md` | Сценарий 2-минутного видео контрольного примера: тайм-коды, действия на экране и речь. |
| `generate_pptx.py` | Скрипт-генератор презентации. |
| `apply_branding.py` | Применяет правки логотипа/подписей к уже готовому `.pptx`, не трогая остальное (например, ваши изменения размера шрифта). |
| `assets/tsu_logo.png` | Логотип университета для левого верхнего угла (положите файл сюда). |

## Колонтитулы (логотип и подписи)

- В **левом верхнем углу** каждого слайда — эмблема университета из `assets/tsu_logo.png`.
  Если файла нет, угол остаётся пустым (логотип просто не вставляется).
- В **правом верхнем углу** — название раздела, в **правом нижнем** — нумерация
  «NN / 17». Размеры этих подписей увеличены.

### Применить правки к уже отредактированному файлу

Если вы вручную меняли презентацию (например, размер шрифта) и не хотите потерять
правки — не пересобирайте через `generate_pptx.py`, а наложите изменения логотипа
и подписей поверх вашего файла:

```bash
python apply_branding.py "ВАШ_ФАЙЛ.pptx" "Готово.pptx" assets/tsu_logo.png
```

Скрипт уберёт старую подпись в левом углу, вставит логотип и увеличит подписи
справа сверху и снизу — всё остальное останется без изменений.

## Шрифты

Презентация рассчитана на шрифты, доступные в Windows / PowerPoint:

- **Заголовки** — `Arial Black` (тяжёлый гротеск);
- **Рукописные акценты** — `Segoe Script` (курсив);
- **Основной текст** — `Arial`.

Если открыть на системе без этих шрифтов, они будут заменены похожими — общая
вёрстка сохранится. Для гарантированно одинакового вида рекомендуется встроить
шрифты в файл: в PowerPoint → *Файл → Параметры → Сохранение → Внедрить шрифты в файл*.

## Пересборка презентации

```bash
pip install python-pptx
python generate_pptx.py
```

Скрипт создаёт файл `Презентация_ВКР_Тропа.pptx` рядом с собой. Всё содержимое и
вёрстка задаются в `generate_pptx.py` — редактируйте текст слайдов прямо в нём и
запускайте заново.
