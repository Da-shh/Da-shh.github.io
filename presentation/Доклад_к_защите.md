# Доклад к защите ВКР (5 минут)

**Тема:** Разработка веб-сервиса построения туристических маршрутов по Тульской
области для людей с ограниченными возможностями здоровья.
**Студент:** Шулепова Д. А., гр. 221321. **Руководитель:** Сафронова М. А.

Расчётное время — около 5 минут. В скобках указаны номера слайдов.

---

**(Слайд 1)**
Уважаемые члены государственной экзаменационной комиссии! Тема моей выпускной
квалификационной работы — «Разработка веб-сервиса построения туристических
маршрутов по Тульской области для людей с ограниченными возможностями здоровья».
Разработанная система называется «Тропа».

**(Слайды 2–3)**
Актуальность работы высока: в России более 10 миллионов граждан с инвалидностью,
а в адаптированной туристической информации нуждается около 30 % населения.
Тульская область ежегодно принимает более полумиллиона туристов, но сведения о
доступности её объектов разрознены, а популярные сервисы — Яндекс Карты, 2GIS,
Tripadvisor — потребности людей с ОВЗ не учитывают.
Поэтому целью работы стала разработка веб-сервиса, который строит туристические
маршруты с учётом доступности среды под конкретного пользователя. Объект исследования —
процессы информационной поддержки планирования поездок для граждан с ОВЗ, предмет —
модели, алгоритмы и программные средства построения инклюзивных маршрутов. Для
достижения цели решены семь задач — от анализа предметной области до защиты
персональных данных.

**(Слайд 4)**
Сравнение с аналогами показало: ни одна из существующих систем не решает задачу
комплексно. «Тропа» — единственная, которая одновременно учитывает девять категорий
ОВЗ, строит маршруты с учётом доступности и автоматизированно собирает данные.

**(Слайды 5–7)**
Остановлюсь на научной новизне работы — это три ключевых результата.
Первое — многопрофильная модель оценки доступности. Каждый объект описывается
паспортом из 51 атрибута и оценивается независимо по девяти категориям ограничений
здоровья. Если у пользователя несколько ограничений, берётся минимальная оценка —
консервативно, в его пользу.
Второе — модификация алгоритма Дейкстры: в вес ребра добавлено слагаемое, штрафующее
за недоступность объекта. Фактически недоступность превращается в дополнительные
метры пути, а оценка всего маршрута считается по «слабому звену» — по самой
недоступной точке.
Третье — методика автоматизированного сбора сведений с помощью языковой модели
YandexGPT по принципу «человек в контуре»: данные извлекаются из текста сайтов,
но применяются только после проверки модератором.
Помимо оценки, система формирует предупреждения о конкретных препятствиях и наглядно
подсвечивает доступность сегментов маршрута на карте: зелёным, жёлтым и красным.

**(Слайды 6, 11)**
Система реализована как клиент-серверное веб-приложение: сервер на Python и FastAPI,
клиент на React, база данных PostgreSQL с пространственным расширением PostGIS,
карты — Яндекс.Карты. Качество автоматического извлечения данных составило
F1 = 0,81.

**(Слайды 12–13)**
Защита персональных данных выполнена по 152-ФЗ: хеширование паролей, токены, HTTPS,
ролевое разграничение доступа; построена модель угроз. Работоспособность подтверждена
контрольным примером — маршрутом для пользователя на инвалидной коляске: все
требования по времени отклика выполнены, маршрут построен за 1,2 секунды. База
заполнена 20 объектами и 18 готовыми маршрутами, проведено тестирование на трёх
уровнях.

**(Слайды 14–15)**
Технико-экономический анализ подтверждает целесообразность проекта: при стартовом
капитале 500 тысяч рублей срок окупаемости — 15 месяцев, рентабельность инвестиций
за три года — более 2000 %.

**(Слайды 16–17)**
Таким образом, цель достигнута, все задачи выполнены. Практическая значимость работы —
в том, что граждане с ОВЗ получают возможность самостоятельно планировать поездки, а
решение готово к тиражированию на другие субъекты России. Разработан работающий
веб-сервис «Тропа», готовый к опытной эксплуатации.
