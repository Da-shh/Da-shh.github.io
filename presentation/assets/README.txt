Сюда положите файл логотипа университета с именем:

    tsu_logo.png

Рекомендации:
- формат PNG с прозрачным фоном (тогда логотип красиво ляжет на серый фон);
- горизонтальный вариант (эмблема + текст) подойдёт лучше всего;
- высота на слайде задаётся в generate_pptx.py (LOGO_HEIGHT_IN, по умолчанию 0.62").

После добавления файла запустите:  python generate_pptx.py
