# Как залить бэкенд и фронтенд на GitHub

Здесь лежат готовые служебные файлы. Вам нужно только скопировать их в свои папки
с кодом и выполнить команды загрузки.

## Что в папках

```
code_templates/
├── backend/
│   ├── .gitignore        ← список того, что не попадёт в Git (секреты, мусор)
│   ├── .env.example      ← шаблон переменных окружения (без секретов)
│   └── README.md         ← описание и инструкция запуска бэкенда
└── frontend/
    ├── .gitignore
    ├── .env.example
    └── README.md
```

## Шаг 1. Скопировать файлы в свои папки

- Скопируйте `code_templates/backend/.gitignore`, `.env.example`, `README.md`
  в корень папки вашего **бэкенда**.
- Скопируйте `code_templates/frontend/.gitignore`, `.env.example`, `README.md`
  в корень папки вашего **фронтенда**.

> `.gitignore` — файл с точкой в начале. Если проводник его «прячет», включите
> показ скрытых файлов.

## Шаг 2. Убрать секреты (если они есть)

Убедитесь, что в папках НЕ лежит ничего из списка ниже (а если лежит — оно и так
не попадёт в Git благодаря `.gitignore`, но проверьте):

- `.env` с реальными паролями/ключами;
- ключи Yandex Cloud: `key.json`, `*.pem`, `service-account*.json`;
- дампы базы: `*.sql`, `*.dump` (там персональные данные!).

Свой настоящий `.env` оставьте на компьютере — он нужен для запуска, но в репозиторий
не уйдёт.

## Шаг 3. Создать репозитории на GitHub

Создайте на GitHub два пустых репозитория (без README), например:
`tropa-api` и `tropa-web`.

## Шаг 4. Загрузить (выполнять в папке с кодом)

Бэкенд:

```bash
cd путь/к/папке/бэкенда
git init
git add .gitignore
git status                       # проверьте: .env и секретов в списке быть НЕ должно
git add .
git commit -m "Initial commit: бэкенд ИС «Тропа»"
git branch -M main
git remote add origin https://github.com/Da-shh/tropa-api.git
git push -u origin main
```

Фронтенд — то же самое, но в папке фронтенда и с remote `tropa-web`:

```bash
cd путь/к/папке/фронтенда
git init
git add .gitignore
git status
git add .
git commit -m "Initial commit: фронтенд ИС «Тропа»"
git branch -M main
git remote add origin https://github.com/Da-shh/tropa-web.git
git push -u origin main
```

## Шаг 5. Финальная проверка

После `git add .` и перед `git commit` выполните:

```bash
git ls-files | grep -iE "\.env$|\.key|\.pem|key.json|\.sql|\.dump"
```

- Если команда ничего не вывела — отлично, секретов в коммите нет.
- Если что-то вывела — уберите из Git (на диске файл останется):

```bash
git rm --cached путь/к/файлу
```

## Если секреты уже попадали в Git раньше

Удаления новым коммитом мало — они останутся в истории. Тогда:

1. **Смените все ключи и пароли**: YandexGPT, `JWT_SECRET`, пароль БД, пароль Redis.
2. При необходимости очистите историю (`git filter-repo` / BFG) или пересоздайте
   репозиторий с нуля.
