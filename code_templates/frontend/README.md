# tropa-web — клиентская часть ИС «Тропа»

Веб-сервис построения туристических маршрутов по Тульской области для людей с
ограниченными возможностями здоровья. Клиентская часть (SPA).

## Стек

- TypeScript, React, Vite
- Яндекс.Карты JavaScript API 3.0

## Быстрый старт

```bash
npm install
cp .env.example .env   # заполните значения
npm run dev            # запуск в режиме разработки (http://localhost:5173)
```

## Сборка

```bash
npm run build          # сборка в папку dist/
npm run preview        # предпросмотр собранной версии
```

## Переменные окружения

См. `.env.example`. Реальный файл `.env` хранится только локально и в репозиторий
не коммитится. Переменные с префиксом `VITE_` доступны в коде через
`import.meta.env`.
